# USB 2.0 枚举（USB Enumeration）深入讲解

> 面向具备 C 语言、MCU 外设和底层驱动基础的嵌入式工程师。以 **USB 2.0 规范**为准，从总线电气层、协议包、标准请求、描述符到 Host/Device 两端驱动实现，系统讲解 USB 枚举全过程。

## 本教程能帮你做什么

学完本教程后，你应当能够：

- 独立解释“设备插入 → 枚举成功”之间总线上发生的每一件事
- 看懂 USB 抓包中的 SETUP / DATA / ACK / NAK / STALL，并与标准请求对应
- 逐字节解析 Device / Configuration / Interface / Endpoint / String / HID 描述符
- 从 Host 与 Device 两端分析枚举状态机与固件响应逻辑
- 排查常见枚举失败：检测不到、Reset 无响应、STALL、地址异常、配置异常等

## 阅读建议

1. **先通读第1、2章**，建立“时间线 + 状态机”心智模型，再精读第3、4章。
2. 第5章和第6章建议对照：一边看伪代码，一边对照抓包字段。
3. 第7章可按问题索引查阅，不必一次读完。
4. 第8章的自测题建议合上前面章节独立作答。

## 规范与范围说明

- **本文以 USB 2.0（含 Low-Speed / Full-Speed / High-Speed）为主**，不展开 USB 3.x 的 SuperSpeed 枚举（如 LTSSM、流协议等）。
- 文中区分两类内容：
  - **USB 标准规定**：设备状态、标准请求、描述符布局、时序下限等
  - **实现相关**：具体 MCU 的 UDC/HCD 寄存器、协议栈 API、Host 是否二次 Reset 等主机策略
- 不确定或依赖实现的细节会明确标注，不以猜测代替规范。
